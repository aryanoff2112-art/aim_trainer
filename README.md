# 🎯 Aim Trainer

A fast-paced Aim Trainer game built using **Python** and **Pygame**.

Improve your reaction time, mouse accuracy, and clicking speed while trying to beat your highest score.

---

## Features

- Dynamic target spawning
- Increasing difficulty over time
- High Score system
- Accuracy calculation
- Speed tracker
- Lives system
- Start Menu
- Restart option
- Game Over statistics
- Progressive target growth speed

---

## Technologies Used

- Python 3
- Pygame

---

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Aim-Trainer.git
```

Move into the folder

```bash
cd Aim-Trainer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the game

```bash
python main.py
```

---

## Controls

| Key | Action |
|------|--------|
| Left Mouse | Shoot Target |
| Space | Start Game |
| R | Restart |
| Esc | Quit |

---

## Gameplay

Every 15 seconds

- Targets spawn faster
- Targets disappear faster
- Difficulty increases

Missing 7 targets ends the game.
