# 🎯 Aim Trainer

A simple Aim Trainer game built using Python and Pygame.

## Features

- 🎯 Random Targets
- 🏆 High Score Saving
- 📈 Progressive Difficulty
- ▶️ Start Menu
- 🔄 Restart Game
- ⏱ Speed Counter
- ❤️ Lives System

## Controls

- Left Click - Hit Target
- Space - Start Game
- R - Restart
- Esc - Quit

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python aim_trainer.py
```
